# ЖК «Колибри-2»

Адаптивная главная страница проекта в виде HTML, CSS и JavaScript. Откройте `index.html` локально или разместите содержимое репозитория на статическом хостинге.

Навигация и мобильное меню работают без серверной части. Кнопки связи открывают звонок в отдел продаж. Изображения взяты из предоставленных пользователем макетов; актуальное наличие и цены квартир на сайте пока не публикуются. CRM и формы заявок не подключены. Предыдущая версия визуального предпросмотра сохранена в файлах `assets/kolibri-*.jpg`.
